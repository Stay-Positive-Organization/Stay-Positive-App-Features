# Quotes: Words to carry library

The quotes in `quotes/library` in Firebase, in rotation order. Ids match Firebase. See [Quotes Home.md](Quotes%20Home.md) for how the daily quote is picked.

**Adding a quote:** add it to the end of this list with the next id, then add the same entry in the Firebase console under `quotes/library` with the next `order`. Never renumber or reuse ids.

**Retiring a quote:** set `active: false` in Firebase and mark it *(retired)* here. Don't delete it.
